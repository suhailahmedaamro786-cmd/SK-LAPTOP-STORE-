# Motion design skill

- Follow docs/ANIMATION-GUIDELINES.md.
- Prefer CSS transforms and opacity; avoid layout thrashing and heavy dependencies.
- Respect prefers-reduced-motion and provide instant alternatives.
- Motion must communicate state or hierarchy, never hide information.
- Keep interactions responsive on low-end mobile devices.
- Do not add animation packages until package compatibility and bundle impact are reviewed.
