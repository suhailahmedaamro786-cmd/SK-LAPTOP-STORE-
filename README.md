# SK LAPTOP STORE

Premium, Pakistan-wide laptop storefront for new and used laptops, with accessories planned for later phases.

**Brand owner:** Mr. Suhail Ahmed Aamro  
**Founder of:** SK DEV TEAM

## Customer experience
Homepage, new/used catalogue, search and filters, product comparison, product details, cart, checkout, order tracking, WhatsApp inquiries and transparent store policies.

## Stack direction
Next.js App Router · React · strict TypeScript · Tailwind CSS · Cloudflare Workers/OpenNext · D1 · R2.

## Important rules
Use only the owner's approved logo asset; do not invent or distort it. Never publish fake stock, reviews, warranty claims, delivery promises or product specifications. Used laptop condition and battery details must be item-specific and honest. Purchase cost, margins, supplier data and private customer information belong only in the private admin system.

## Status
Phase 1 documentation committed. Application code, integrations, automated tests and production deployment are not yet complete or verified.
